# 관심 분야 설문 서비스

Streamlit으로 제작한 로그인 기반 설문 포트폴리오입니다.

## 주요 기능

- 로그인 검증
- 관심 분야 단일 선택
- 취미 복수 선택
- 설문 결과 출력
- 다시 설문 제출
- 로그아웃
- 세션 상태 관리

## 테스트 계정

- ID: `1234`
- Password: `1234`

## 로컬 실행

```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

## 배포

Streamlit Community Cloud에서 이 GitHub 저장소를 선택한 다음 Main file path에
`streamlit_app.py`를 입력합니다.
